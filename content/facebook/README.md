# Facebook Distribution & Open Graph Hooks

You publish externally (SocialBee or similar) with the link in the first comment. This file is about what the **site** provides so that scrapers and humans see a strong preview.

## How the OG hooks work

Every guide sets an `og:title` that is a **hook, not the H1**, plus a 150–160 character `og:description`. When you paste the URL into a post or the first comment, Meta reads exactly these tags.

After editing a page, force a refresh: Facebook Sharing Debugger → “Scrape Again”. Otherwise you may see a cached preview.

## Posting hygiene (platform rules, not tricks)

- One to two posts a day at most while the page is new.
- Rotate the hook wording; never post identical text twice.
- Link in the first comment for the first month, then test link-in-post and compare.
- Use the plain URL, no link shorteners.
- Never buy engagement. It damages page quality more than it helps reach.

## UTM pattern

`?utm_source=facebook&utm_medium=social&utm_campaign=<slug>`

## What to measure

Link click-through rate, Page RPM by article in AdSense, time on page from social, and bounce. A high click rate with a high bounce rate means the hook overpromised — rewrite it rather than scaling it.
