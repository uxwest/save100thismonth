Save100ThisMonth

Get this site

Option A — Download the ZIP from GitHub

  1. Open the repository: github.com/uxwest/save100thismonth
  2. Click the green Code button → Download ZIP.
  3. Unzip it — the site is the folder itself (index.html at the root).

Option B — Clone it

git clone https://github.com/uxwest/save100thismonth.git

Preview locally

From the project folder: python3 -m http.server 8000 then open http://localhost:8000.

Publish it

The site is 100% static. It works on GitHub Pages, Cloudflare Pages, Netlify or any web server — no build step, no database.
