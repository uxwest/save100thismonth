Site files and deployment

This site is fully static. No build step, no database, no server-side code.

Structure

  • assets/css/style.css: the single stylesheet
  • assets/js/ui.js: the mobile menu toggle, progressive enhancement only
  • assets/img/: SVG illustrations and charts
  • One folder per page, with index.html inside

Local preview

python3 -m http.server 8000 # then open http://localhost:8000

Deployment

Any static host works: GitHub Pages, Cloudflare Pages, Netlify or a plain web server. For GitHub Pages, set the branch to main and the folder to root.
